# 🎙️ Sinhala Audio Upload Directory

මෙම ෆෝල්ඩරය තුළට ඔබ කතා කරන සිංහල ඕඩියෝ ගොනුව (.mp3, .wav, .m4a, .ogg) Upload කරන්න.

## 🚀 උපදෙස් (How to Use):
1. **GitHub වෙබ් අඩවියෙන් කෙලින්ම Upload කිරීම:**
   - ඉහළ ඇති **"Add file"** -> **"Upload files"** ක්ලික් කරන්න.
   - ඔබගේ සිංහල හඬ පටය (Voice Audio File) Drag & Drop කර Commit කරන්න.
2. **GitHub Actions මඟින් ස්වයංක්‍රීයව:**
   - ඔබ ඕඩියෝ එකක් දැමූ සැණින් GitHub Action එක ක්‍රියාත්මක වේ.
   - එය ඔබගේ සිංහල හඬට අදාළව කාල සටහන් (Timestamps) සහිත **.srt Subtitle ගොනුව** නිර්මාණය කර `subtitles/` ෆෝල්ඩරය තුළට සුරකියි.
3. **බාගත කිරීම (Download SRT):**
   - **Actions Tab** එකට ගොස් **Artifacts** මඟින් හෝ `subtitles/` ෆෝල්ඩරය මඟින් කෙලින්ම .srt ගොනුව බාගත කරගත හැක.
